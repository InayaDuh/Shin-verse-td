# TDAY@ SHINVERSE

# Spend a day with me in my world.

Welcome to Shin-Verse! It's a little interactive game inspired by Crayon Shin-chan where you get to spend a day in Shinchan's chaotic world. From waking up in the morning to deciding what to do after school, you get to make choices along the way!

# About the Project

Shin-Verse is a browser-based game and my second coding project. I wanted to make something related to Shinchan because I love the anime, and I thought it would be fun to turn that into a game.

The idea is pretty simple. You go through different parts of Shinchan's day, look at pictures, and make choices that decide what happens next. I wanted it to feel a little like a visual novel, but with my own ideas added to it.

Honestly, making this was harder than I expected. Since this is only my second project, I still have a lot to learn, especially when it comes to JavaScript. Sometimes I knew what I wanted to happen in the game but didn't know how to make it work in code. There were also times when I messed things up and had to figure out how to fix them. It took patience, and I had to learn things along the way instead of expecting everything to work on the first try.

# Features

 Interactive choices: Make decisions as you go through the game.
Picture sequences: Different pictures appear as the story moves forward.
 A day in Shinchan's world: Experience different parts of his day, from morning to after school.
Anime-inspired visuals: A playful look inspired by Crayon Shin-chan.
 Browser-based gameplay: Play directly in your browser without installing anything.

# Built With

 HTML

# Design & Assets

I worked on the look of the game and chose the pictures for its different scenes. I wanted the visuals to match the funny and slightly chaotic feeling of Shinchan.

I used the Gaegu font from Google Fonts because I liked its handwritten look. It suited the style I was going for.

# AI Assistance

I did most of the planning and design based on my own ideas. While working on the project, I accidentally undid some of my original JavaScript, which was honestly frustrating. I used ChatGPT to help reconstruct the JavaScript for the evening scene and clean up the HTML for it.

The code was reconstructed using my existing idea for the game, the pictures I had chosen, and the sequence I wanted the scenes to follow. I'm still learning JavaScript, so I'm trying to get better at understanding my code and fixing problems myself instead of relying on AI for everything.

# What I Learned

This project taught me that making a game is not as easy as just having a good idea. You have to figure out how all the little parts work together, and sometimes one small problem can stop something else from working.

I got more practice with HTML, CSS, and JavaScript, especially connecting buttons to actions and organising different scenes. I also learned the hard way that saving your work regularly is REALLY important. Losing code is not fun, trust me.

I'm still a beginner, and there are things I could have done better. But I'm glad I kept working on it instead of giving up when things got confusing. I hope to use what I learned here in my next projects.
